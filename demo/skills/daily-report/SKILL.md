# 每日简报技能指令

当用户请求「生成每日简报」「今日速览」或类似意图时，请执行以下步骤：

1. 调用 `get_current_time` 工具获取当前日期与时间。
2. 询问或确认用户关心的城市；若用户已给出城市，直接调用 `get_weather` 工具查询该城市天气。
3. 将时间与天气信息组织成一段简洁友好的中文简报，格式如下：
   - 开头一句问候语（依据时段选择「早上好 / 下午好 / 晚上好」）；
   - 当前日期与时间；
   - 指定城市的天气描述；
   - 一句简短的出行或心情建议。
4. 若用户未指定城市，默认使用「北京」，并在简报中注明这一点。

请保持简报简短，避免堆砌无关信息。
